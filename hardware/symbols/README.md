# Symbols copied from KiCad

The few KiCad library symbols the schematic uses, copied from KiCad 10.0.6's
own symbol libraries (`/usr/share/kicad/symbols` on Arch Linux, package
`kicad-library` 10.0.6-1), so the schematic can be generated and checked on a
machine without KiCad and gives the same result everywhere.

These files are KiCad's, not this project's: the KiCad libraries are licensed
CC-BY-SA-4.0 with an exception that lets designs using them carry any licence
(<https://www.kicad.org/libraries/license/>). Do not edit them by hand. To take
a newer version, copy the symbol from KiCad's library again and regenerate.
